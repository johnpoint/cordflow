ModeSwitch reveals expert-only workspaces or capabilities without changing ordinary task behavior.

```jsx
<ModeSwitch label="Advanced mode" checked={advancedModeEnabled} onChange={setAdvancedModeEnabled} />
```

The track is square and hairline-bordered; the 4px rectangular thumb uses muted ink when off and Apple Blue when on. Always show the text state, preserve the native checkbox for keyboard access, and keep advanced mode off by default.
